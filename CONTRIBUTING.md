# Contributing

This is a conference leave-behind. It is small on purpose and it is meant to
stay accurate rather than to grow.

## Corrections are the main thing

If you find a dead link, a wrong date, a misattributed figure, or a claim a
source does not actually support, please open an issue or a pull request. That
last category matters most. A citation attached to a claim the source never made
reads perfectly and survives review until somebody opens the paper.

## Standards for anything added

**Cite the primary source.** The publishing organisation's own page, not a
summary of it, not a news article about it, not a vendor blog.

**Verify the URL resolves before submitting.** If a `.mil` or `.gov` host returns
403 to an automated check but opens in a browser, note that in the pull request.

**Do not guess a URL.** If you cannot find and verify one, write the full
citation and leave it unlinked. That is the existing convention and it is
deliberate.

**Quote government standards verbatim.** The Proficiency Code Key wording is
exact, from published CFETPs. Do not paraphrase it into something tidier.

**Say when something is a synthesis.** The gate and the levels of autonomy are
ours, reduced from cited work. They are labelled that way. Anything new that
reorganises a source into a cleaner model must be labelled the same way.

## Style

Plain English. No em-dashes. Short sentences. No marketing language.

Write for someone reading on a phone between conference sessions.

## What does not belong here

Vendor marketing, logos, or branding. Anything requiring a login. Screenshots
that go stale. Anything that cannot be sourced.
